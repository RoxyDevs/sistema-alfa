# SISTEMA ALFA

## Estructura de archivos

- assets/images/: aquí colocas las imágenes de la web.
- assets/pdf/: aquí colocas el PDF que vas a entregar.

## Cómo usar el PDF

1. Guarda tu archivo PDF en assets/pdf/.
2. Si quieres mostrarlo directamente en la web, usa una ruta como:
   - /assets/pdf/SistemaAlfa.pdf
3. Si lo quieres entregar desde Firebase, puedes subirlo a Firebase Storage y usar el enlace generado.

- Imagen: /assets/images/mi-imagen.png
- PDF: /assets/images/mi-archivo.pdf
